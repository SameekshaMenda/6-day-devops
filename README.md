# 6-Day DevOps Learning Program

This repository contains my learnings and hands-on practice tasks completed during a **6-day DevOps Learning Program**. The aim was to understand the foundational tools and practices used in the DevOps lifecycle, including version control, CI/CD pipelines, containerization, and infrastructure as code.

## 🗓️ Program Overview

- **Duration**: 6 Days
- **Topics Covered**: Git & GitHub, Docker, Jenkins, CI/CD, AWS, and Terraform
- **Format**: Daily learning tasks and practice exercises

## 📚 Contents

The repository includes notes, screenshots, and/or code related to each day’s learning module.
